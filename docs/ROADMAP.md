# PokerSense 路线图

更新于 2026-10-06。阶段性完成或方向调整时更新本文件。

## 目标

在 AA 扑克 6–8 人桌上做**实时策略分析**：画面出现 → 识别牌局 → 在行动时限内显示
有依据的策略参考。用途是学习，赛后复盘放到下一阶段。

## 现状（2026-10-06）

| 部分 | 现状 |
|---|---|
| 识别 | 牌、公牌、底池、座位、筹码、动作等识别器都有，但只在开发录像上验证过，没有完整的实时链路验收 |
| 状态 | 权威状态引擎、手牌边界、边池、合法动作都已实现 |
| 胜率 | 枚举、蒙特卡洛、范围对范围计算都可用 |
| 翻前 | 只有一份 6/9 人首个加注的启发式表（非求解器结果），7/8 人借用 9 人表 |
| 翻后 | 能查询提前算好的 3 个合成单挑局面（2 个河牌 + 1 个转牌，共 30 个节点）；没有实时求解 |
| 研究遗产 | 自训练 MCCFR 和本地大模型两条路线都已证明不可用（完整牌局覆盖约 6%，模型 NO_GO），**已冻结** |

## 关键决策

1. **不自研全街策略，也不自研求解器。**单挑翻后用现成开源求解器（TexasSolver，或 postflop-solver
   的 MIT 版本），作为独立进程在本机调用，求解器本身不进仓库。
2. **分层出结果**，每一层都要能在时限内给出答案：

   | 层 | 内容 | 方法 |
   |---|---|---|
   | 1 | 牌局状态 | 识别 + 状态引擎 |
   | 2 | 胜率、底池赔率、所需胜率、SPR | 直接计算 |
   | 3 | 保险是否值得买 | 按补牌数精确计算 |
   | 4 | 翻前建议 | 查翻前表 |
   | 5 | 翻后单挑 | 河牌实时求解，转牌用小树实时求解，翻牌提前算好再查表 |
   | 6 | 翻后多人底池 | 只给第 2 层的数学参考，并明确标注“无求解器依据” |

3. 3 人及以上的翻后求解属于研究级难题，等前面各层稳定后再评估。

## AA 特殊规则（来自开发录像观察，金额规则尚未完全确认）

- **保险**：只在全下之后出现，是独立的附加决策，可以按补牌数精确计算。
- **暴击**：每位玩家额外投入，录像里见过 5BB。**蘑菇**：新庄位额外投入，见过 2BB。
  两者作用都类似前注：底池变大，翻前应打得更宽。具体数值以本桌设置为准。
