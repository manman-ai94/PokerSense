# V2 有限翻前支持集审计

本轮承接已关闭的 V2 可执行性实验和本地通用模型诊断，目标是定位扑克专用策略的
覆盖缺口。保留原 V2 编码器、MCCFR、九份 checkpoint 和平均策略，不拟合、不补动作。
用户“继续”授权推进该有限审计；没有启动真实采集、云训练或实战建议。

## 为什么先审计

原 V2 的 5325 次拒答中，4630 次查询键不在训练表，695 次虽在 regret 表却没有平均策略。
现有 SIMPLE next-player 平均方式仅在指定非 traverser 分支累计 average；所有遍历都会
增加 visits 并创建 regret 行。因此 regret 表存在不等于发生过非零更新，更不等于已导出。
不能将 regret matching 的当前策略填入平均策略空洞，也不能把所有访问无权重地加入平均值。

工程测试用可枚举的小型对局构造了“两轮、非零 regret、无 average”的实际反例，说明该
结构可以发生。它不是新扑克训练结果，也不能倒推旧某次访问的 traverser 角色；旧记录
没有记录这些角色，逐次原因保持 UNKNOWN。

## 评分前冻结的支持范围

- 人数 6／7／8；原训练布局为 occupied=range(n)，BTN=n−1。检查每个已占物理座位，
  不扩称任意八槽布局、按钮轮换或座位等价。
- 100BB、原明确模拟桌规，保留精确下注历史与金额，不代替用户真实桌规。
- 每座位 169 类起手牌：13 对子、78 同花、78 非同花；等权枚举不等于真实发牌频率。
- 三种脚本前缀：其他玩家弃牌到 Hero 首次行动、其他玩家跟注到 Hero 首次行动、
  跟注到 Hero 且 Hero 跟注后下一位最小加注、其余玩家跟注到 Hero 再次行动。
- 21 个位置 × 169 × 3 = **10647 个计划支持点**。查询每个人数原来的三个种子
  1103／2207／3301，共 **31941 条资产记录**。这些是发展诊断，不是新的独立强度测试。
- 完整52张合法牌序中只指定 Hero 的代表底牌；两组隐藏补全种子 8300101／8300102 必须
  产生相同的公开观察和键。模型输入不含补全种子、对手底牌或未来牌。
- 工程反例覆盖全部1326种具体起手组合的169类花色等价；完整路径和合法菜单保留。

本次固定模拟规则和布局下，seat 2 是最后行动的 straddler。其余人全部弃牌会直接终局；全部跟注后
seat 2 check/call 会关闭翻前。因此每个人数的两组各169个点不成立，共1014个支持点／
3042条资产记录，必须保留 NOT_APPLICABLE。可构造决策为9633个点／28899条资产记录。
首位 seat 3 的前两种前缀相同，报告另列唯一 exact／abstract 键，不能当独立覆盖。

## 分类、预算与停止规则

使用实际 FrozenResearchPolicyV2 loader、inspect_lookup 与 distribution，再读原 checkpoint。
校验原 manifest／receipt、文件哈希、规则和种子绑定、恢复后的平均策略与导出内容完全一致。

分别统计 HIT、UNVISITED、REGRET_TABLE_ONLY_ZERO、REGRET_ONLY_NONZERO、AVERAGE_ZERO_MASS、
NOT_APPLICABLE、构造／绑定／菜单错误、INTERRUPTED、NOT_RUN。HIT 另报平均策略是否非均匀；
命中、非均匀和实际盈利三个概念分开。全部计划分母保留，不成立点与可构造分母分别显示。

源代码、运行环境、旧资产字节、规则和矩阵在查询前冻结。唯一批次最多600秒，包含输入验证、
查询和保存；前450秒用于验证和查询，剩余预留报告重核与退出，590秒外部监督可终止自有进程。
每个分片保存一次 attempt 和原始
查询日志；完整分片再提交哈希 receipt。中断日志保留，其未提交分片作为 INTERRUPTED，
其余为 NOT_RUN；禁止重新启动该批次以挑选结果。报告从原资产及完整规则重核已记录支持点、
分布和分类，自行改HIT后重新签署日志哈希也不能通过。监督异常后可独立 report 重建分母；
它只重验已有点，不增加样本、不选择动作或更新策略。

本轮到覆盖审计及机制归因为止。不修改采样权重或平均器，不延长旧训练，不从任意中途
局面重启有偏训练，不开放真实动作建议。不完整或缺失结果不计算收益，本轮 EV 始终为空。
唯一后续目标是平均策略收集的采样覆盖与权重正确性：先用可枚举小型对局核对目标平均量、
采样概率和实际收集结果，再决定是否改变收集方式。

## 复现

在本分支源码及固定 Python／PokerKit 环境中执行。旧研究目录只读，输出必须全新：

```powershell
$env:PYTHONPATH='src'
$env:PYTHONUTF8='1'
python -m tools.audit_aa_preflop_support freeze --source-study '<原V2研究目录>' --output '<全新审计目录>'
python -m tools.audit_aa_preflop_support run --output '<同一审计目录>'
# 核对旧点并重建报告，不增加支持点、训练或第二批预算：
python -m tools.audit_aa_preflop_support report --output '<同一审计目录>'
```

实际结果与独立复核在封顶批次结束后追加，不覆盖原研究或失败结果。
