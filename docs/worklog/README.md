# 每个 PR 的工作记录

每个合并的改动在这里加**一个新文件**写它的记录，不直接改 `docs/WORKLOG.md`：
两个 PR 不碰同一个文件，GitHub 就不会因为工作记录报冲突、不跑检查。

- 文件名：`<日期>-<分支名>.md`，分支名里的 `/` 换成 `-`，例如 `2026-10-15-claude-ci-speedup-5yxfv0.md`；
  同一分支第二个 PR 加 `-2`。
- 内容和以前一样：以 `### 日期 · 分支（标题）` 开头，最多 5 行，写做了什么、怎么做的、怎么验证的、还剩什么。
- 每晚的例行检查跑 `python tools/worklog_rollup.py`，把这里的记录按新到旧并进 `docs/WORKLOG.md` 的“记录”最上面，
  并删掉已并入的文件（单独一个 PR）。人看记录仍然只看 `docs/WORKLOG.md`，加上这里还没并进去的几条。
